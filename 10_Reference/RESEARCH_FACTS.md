## Dalil shakli

`infra/VERSIONS.lock.md` va `knowledge/vendor-evidence/` yozuvi: `claim_id`, `source_url`, `checked_at`, `effective_at`, version/commit/package digest yoki akkaunt, `observed_result`, redacted `evidence_ref`, `owner`, `recheck_trigger`. Narx uchun valyuta va birlik, API uchun versiya, xavfsizlik uchun advisory va o‘rnatilgan paket hash’i yoziladi. Release vaqtida aynan o‘sha binary/image/config ishlagani hash bilan solishtiriladi. “Latest” tag runtime lock emas.

Meta sahifasi rate-limit yoki yopiq akkaunt UI sabab o‘qilmasa feature taxmin bilan yopilmaydi; nazoratli akkaunt darajasidagi test dalili olinadi. QualifiedLead optimizatsiyasi faqat (a) akkaunt eligibility dalili **va** (b) F2’da Analyst o‘lchagan oylik hajm owner mo‘ljali (~200 lead/oy) va Meta’ning joriy rasmiy talabidan (sanasi bilan [D] manba) kattasiga yetsa tanlanadi; aks holda `Lead` bo‘yicha optimizatsiya, qualified esa guardrail (Q29.1 ✅; `vendor.qualified_optimization` qiymati: `supported`, `measured_monthly_volume`, `vendor_requirement_ref`, `selected_goal`). CAPI eski event/dedup kabi sonli oynalari pinned rasmiy kontrakt bilan qotiriladi.
