## 3. Qarorni belgilaydigan texnik topilmalar

### A. To‘g‘ridan-to‘g‘ri persona va delegatsiya bir xil emas

Routed chat `AdClawAgent` ReAct agentini, toolbox va MCP bilan yaratadi. Ammo `execute_delegation` specialist’ni SOUL/system prompt bilan **bir martalik LLM chaqirig‘i** orqali ishlatadi: `chat_model([sys_msg, user_msg])`. Bu yo‘lda specialist uchun ReAct loop, toolkit yoki MCP registratsiyasi yo‘q. Kod izohining o‘zi “For MVP” deb boshlanadi; bu butun loyiha yorlig‘i emas, aynan delegatsiya yo‘lining cheklovi. Demak “coordinator Ads Manager’ga berdi” degan holatni Ads API operatsiyasi bajarilgan deb hisoblab bo‘lmaydi. [Routed agent](https://github.com/citedy/adclaw/blob/25bf9601f30f069dc5c24f4845abc9ce120d809b/src/adclaw/app/runner/runner.py#L918-L930), [delegation executor](https://github.com/citedy/adclaw/blob/25bf9601f30f069dc5c24f4845abc9ce120d809b/src/adclaw/agents/tools/delegation_executor.py#L37-L97).

`TaskStrategy`/outcome/dependency/pivot modeli mavjud. Lekin coordinator cron helper’i async `execute_delegation`ni sync funksiya kabi `run_in_executor`ga uzatadi va qaytgan natijada `startswith` chaqiradi. **Statik xulosa:** real funksiya ishlatilsa natija coroutine bo‘lishi kutiladi va shu yo‘l mos kelmaydi; runtime’da qayta ishlab chiqarilmadi. Repository qidiruvida helper production chaqiruvchisi topilmadi: ta’rif, eksport va testlar chiqdi. Persona cron job builder’i uchun ham ta’rif va testlar chiqdi; ko‘rilgan umumiy cron executor esa `runner.stream_query`ni ishlatadi. Shuning uchun avtomatik synthesis→mutaxassis→dalilli ijro zanjiri tayyor va ulangan deb qabul qilinmaydi. [Coordinator helper](https://github.com/citedy/adclaw/blob/25bf9601f30f069dc5c24f4845abc9ce120d809b/src/adclaw/agents/coordinator/cron_handler.py#L68-L124), [models](https://github.com/citedy/adclaw/blob/25bf9601f30f069dc5c24f4845abc9ce120d809b/src/adclaw/agents/coordinator/models.py), [cron builder](https://github.com/citedy/adclaw/blob/25bf9601f30f069dc5c24f4845abc9ce120d809b/src/adclaw/app/crons/persona_sync.py), [cron executor](https://github.com/citedy/adclaw/blob/25bf9601f30f069dc5c24f4845abc9ce120d809b/src/adclaw/app/crons/executor.py).

Persona model maydonlari delegatsiyada o‘qiladi, ammo ko‘rilgan to‘g‘ridan-to‘g‘ri chat yo‘li agentga model uzatmaydi va agent global active model factory’sini chaqiradi. Persona card’dagi model tanlovi barcha ijro yo‘llarida bir xil qo‘llanadi degan da’vo qabul testi bilan yopilishi kerak. [Delegatsiya model resolution](https://github.com/citedy/adclaw/blob/25bf9601f30f069dc5c24f4845abc9ce120d809b/src/adclaw/agents/tools/delegation_executor.py#L58-L84), [agent model yaratishi](https://github.com/citedy/adclaw/blob/25bf9601f30f069dc5c24f4845abc9ce120d809b/src/adclaw/agents/react_agent.py#L180-L194).

### B. MCP tanlash vakolatni izolyatsiya qilmaydi

Bo‘sh `mcp_clients=[]` **hech qanday client yo‘q** degani emas: runner uni `None`ga aylantiradi, manager esa barcha ulangan clientlarni beradi. Bo‘sh skill ro‘yxati barcha active skilllarga tushadi. Bu AdClaw’ning orqaga moslik semantikasi; Wolter uchun default-deny talabi bilan alohida moslashtiriladi. [Runner](https://github.com/citedy/adclaw/blob/25bf9601f30f069dc5c24f4845abc9ce120d809b/src/adclaw/app/runner/runner.py#L429-L432), [client selection](https://github.com/citedy/adclaw/blob/25bf9601f30f069dc5c24f4845abc9ce120d809b/src/adclaw/app/mcp/manager.py#L173-L195), [skills](https://github.com/citedy/adclaw/blob/25bf9601f30f069dc5c24f4845abc9ce120d809b/src/adclaw/agents/react_agent.py#L285-L308).

File read/write/edit, browser, email va skill patch vositalari persona bo‘yicha alohida ruxsat tekshiruvisiz toolbox’ga qo‘shiladi. Shell active provider `adclaw-host-ai` bo‘lmaganda odatda yoqilgan; Wolter’dagi OpenRouter ham shu shartga kiradi. File tool mutlaq yo‘lni o‘z holicha qabul qiladi; shell OS jarayonining vakolatida ishlaydi. Demak UI’dagi MCP ro‘yxati Meta kalitini yashirish yoki gateway bypass’ini to‘sish kafolati emas. [Toolbox va shell sharti](https://github.com/citedy/adclaw/blob/25bf9601f30f069dc5c24f4845abc9ce120d809b/src/adclaw/agents/react_agent.py#L73-L82), [built-ins](https://github.com/citedy/adclaw/blob/25bf9601f30f069dc5c24f4845abc9ce120d809b/src/adclaw/agents/react_agent.py#L217-L280), [file path](https://github.com/citedy/adclaw/blob/25bf9601f30f069dc5c24f4845abc9ce120d809b/src/adclaw/agents/tools/file_io.py#L14-L28), [shell](https://github.com/citedy/adclaw/blob/25bf9601f30f069dc5c24f4845abc9ce120d809b/src/adclaw/agents/tools/shell.py).

### D. Xarajat, fallback va trace

Fallback zanjiri mavjud, lekin `enabled=False` boshlang‘ich qiymat; demak Q44.3’dagi fallback yo‘q siyosatini saqlash mumkin. Alohida xavf: active LLM config yo‘q bo‘lsa factory `DASHSCOPE_API_KEY` va `qwen3-max`ga o‘tadi. Wolter adapteri bunday default’ni rad etib, konfiguratsiya xatosida to‘xtashi kerak. Barcha LLM chaqirig‘i mavjud llm-proxy’dan o‘tadi; agentga bevosita OpenRouter kaliti berilmaydi. [Fallback config](https://github.com/citedy/adclaw/blob/25bf9601f30f069dc5c24f4845abc9ce120d809b/src/adclaw/providers/models.py#L93-L114), [factory](https://github.com/citedy/adclaw/blob/25bf9601f30f069dc5c24f4845abc9ce120d809b/src/adclaw/agents/model_factory.py#L613-L624).

Tekshirilgan runner/config/provider yo‘llari va `budget`, `spend_reservations`, `trace_id` qidiruvlari Wolter talabi darajasidagi umumiy spend ledger yoki Langfuse run-cost shartnomasini ko‘rsatmadi. Host AI xabar kvotasi ham Wolter cap’i bilan bir xil narsa emas. [Usage proxy](https://github.com/citedy/adclaw/blob/25bf9601f30f069dc5c24f4845abc9ce120d809b/src/adclaw/providers/store.py#L638-L702), [runner](https://github.com/citedy/adclaw/blob/25bf9601f30f069dc5c24f4845abc9ce120d809b/src/adclaw/app/runner/runner.py).

Log, diagnostics, error traceback va session persistence mavjud; ularni audit trace bilan tenglashtirish mumkin emas. Bu jadval [owner qarorlari](../00_Decisions/DECISION_LOG.md) va [production shartnomalari](../11_Production_Contracts/INVARIANTS.md) talablarini kamaytirmaydi. Yuqoridagi texnik bo‘limlardagi manbalar AdClaw tomoni dalili; “saqlanadigan ish” — Wolter uchun muhandislik xulosasi.

## 6. Uch variant va qayta ko‘rish sharti

| Variant | Hukm | Sabab |
|---|---|---|
| Butun Project OS/Paperclip/Hermes’ni almashtirish (`replacement_proposal`) | **Hozir tavsiya etilmaydi** | Ijro, nazorat va migratsiya qamrovi katta; production talablari ishi kamayishi dalillanmagan; delegation/runtime tafovutlari bor. |
| AdClaw’ni cheklangan qo‘shimcha worker/UI sifatida moslashtirish (`restricted_runtime_candidate`) | **Shartli nomzod** — faqat quyidagi dalil paketidan keyin | Faqat mavjud gateway + llm-proxy orqali, kalitsiz/PIIsiz, tashqi egress cheklovi va immutable skill’lar bilan; doimiy ikkita orkestratorni saqlash xarajati ham baholanadi. |
| Tanlangan design/checklist’ni moslashtirish (`reference_only` doirasida) | **Hozir tavsiya etiladi** | Persona UX, MCP lifecycle, session persistence va audit strukturasini olish mumkin; butun paket, umumiy benchmark yoki yangi vakolat avtomatik ko‘chmaydi. |

AdClaw keyinchalik haqiqiy runtime nomzodi bo‘lsa (`restricted_runtime_candidate` holatiga o‘tish va ADR-023 ni qayta ko‘rish uchun) alohida dalil paketi talab qilinadi: (1) approved komponent/provenance ro‘yxati va qotirilgan build; (2) tagged/direct/delegated persona, model va cron uchun bir xil shartnoma testlari; (3) Meta/amoCRM/OpenRouter kalitlari va PII’ga yo‘l yo‘qligi, gateway/llm-proxy chetlab o‘tilmasligi; (4) approval revision, duplicate/uncertain execution, concurrency cap va kill sinovlari; (5) trace/cost, backup/restore va operator drill; (6) mavjud yechimga nisbatan o‘lchangan sifat, xarajat va xizmat yuki. Barcha live ishlash uchun avvalgi owner approval va tegishli qabul gate’lari o‘z kuchida qoladi.

**Yakuniy tavsiya:** hozirgi arxitektura saqlanadi; AdClaw `reference_only` sifatida qoladi, vendor dependency tekshiruvi (`vendor.component_locks`) va ADR-023 qayta ko‘rish mezonlari amal qiladi. Hozir arxitektura migratsiyasi boshlanmaydi. Avval design/reference’dan foyda olinadi; agar worker nomzodi tekshirilsa, to‘liq production shartnomalaridan o‘tgan holatgina qabul qilinadi. Vaqt/ROI tejalishi uchun o‘lchov yo‘q, shuning uchun foiz yoki pul va’dasi berilmaydi.
